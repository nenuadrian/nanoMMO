# Weapons

What the players hold. Like the monsters, they're in git, as their licence lets anyone share them.

| File | What | From | Licence |
|---|---|---|---|
| `sword.glb` | Sword, by [Quaternius](https://quaternius.com) | [Poly Pizza](https://poly.pizza/m/ajOJ2NLz5m), as glTF | [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), public domain |

The file is as it comes from Poly Pizza. The items file, `content/items.txtpb`, says how long the
client draws it and where the hand holds it, and the client puts it in each player's right hand.
