# Music

The music the client plays in the world is "Background Music" by
[Pavel Bekirov](https://pixabay.com/users/paulyudin-27739282/), from
[Pixabay](https://pixabay.com/). Pixabay's licence lets us use it in the game, but not hand out the
file on its own, so it stays out of git, and you download your own copy.

Find the track on Pixabay by its id, 607592, download it, and save it in this folder as
`background.mp3`. The build copies this folder next to the client, which plays the file from there.
Without it, the client plays no music.
